# Craft Planner

Клиентский мод для NeoForge 1.21.1 (Java 21), который планирует большие сборки.

Наводишь курсор на предмет в любом интерфейсе — EMI, JEI или обычном инвентаре — и
добавляешь его в план. Мод разворачивает предмет в дерево крафта до нужной глубины,
считает, сколько крафтов требуется, и показывает, каких материалов не хватает, с
учётом того, что уже лежит в инвентаре. Дерево видно и в HUD, и в отдельном окне,
его можно сворачивать по веткам, выбирать вариант рецепта и обрезать ветку
(«срез» — предмет планируется как материал, а не как то, что нужно скрафтить).
План, выборы рецептов и срезы сохраняются между запусками игры.

Мод клиентский: сервер ставить не нужно, он ничего не пишет в мир и не влияет на
других игроков.

## Сборка

```
./gradlew build
```

В PowerShell — `.\gradlew.bat build`. Готовый jar появляется в `build/libs/`.
Положи его в `mods/`, вместе с NeoForge 21.1.x для Minecraft 1.21.1.

Для разработки: `./gradlew runClient` запускает игру с модом, `./gradlew build test`
собирает и прогоняет юнит-тесты чистой логики (движок дерева, арифметика количеств,
раскладка панели).

## Клавиши

Все они переназначаются в «Настройки → Управление → Craft Planner».

| Клавиша | Действие |
| --- | --- |
| N | добавить предмет под курсором в план и открыть окно количества |
| K | список запланированных целей: изменить количество, убрать, переключить фильтр руд |
| G | окно дерева крафта: сворачивать ветки, выбирать рецепт, смотреть нехватку |
| V | показать или скрыть дерево поверх экрана (HUD) |
| O | редактор раскладки панели: перетащить, изменить размер и масштаб текста |

## Файлы

Лежат в `config/` игрового каталога.

| Файл | Содержимое |
| --- | --- |
| `craftplanner-client.toml` | настройки: глубина и размер дерева, цвета и порог «частично есть», фильтр руд, позиции панели |
| `craftplanner-plan.json` | сами цели и их количества |
| `craftplanner-choices.json` | какой вариант рецепта выбран для предмета |
| `craftplanner-cuts.json` | срезы дерева |

## Зависимости

Обязательна только NeoForge. EMI и JEI — опциональны: без них мод работает, просто
не подсказывает рецепт по наведению из этих интерфейсов и не определяет поле поиска
в них.
